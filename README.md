# USYD Shuttle Finder

A small mobile-friendly timetable helper for University of Sydney campus shuttle routes A, B and C. Camden D is intentionally omitted.

Open `index.html` in a web browser or publish it with GitHub Pages.

Timetable entries were transcribed from the University shuttle timetable page. Calendar dates are based on the University student wall calendars supplied for 2026 and 2027. This prototype is not live bus tracking and does not guarantee service on public holidays or days with unclear operating conditions.

Source: https://www.sydney.edu.au/about-us/campuses/getting-to-campus/campus-bus-timetables.html
